# M0 third-party licenses

The project uses MIT. Declared licenses and exact versions for the locked dependency graph are recorded in [Rust inventory](licenses/rust.tsv) and [npm inventory](licenses/npm.tsv), generated by `scripts/record-licenses.py`. Platform-specific and build/test dependencies are included; an inventory entry does not imply it ships in the Linux binary. Installed crate/package distributions contain their upstream license texts.

Direct dependencies introduced or retained for M0:

| Dependency | Purpose | License |
| --- | --- | --- |
| Tauri, tauri-build, Tauri API/CLI | Native shell, IPC, assets, packaging | MIT OR Apache-2.0 |
| Serde, serde_json | Structured IPC serialization and tests | MIT OR Apache-2.0 |
| Svelte, Svelte Vite plugin, svelte-check | UI and type checking | MIT |
| TypeScript | Strict frontend types | Apache-2.0 |
| Vite | Frontend development and production builds | MIT |
| Vitest | IPC boundary tests | MIT |
| Prettier, prettier-plugin-svelte | Frontend formatting | MIT |
| tauri-driver | External desktop test tool, version 2.0.5 | MIT OR Apache-2.0 |

Lyra artwork and icons are project-owned SVG/CSS artwork with no external image/font assets. Linux GTK/WebKitGTK and their system dependencies retain their upstream licenses and are supplied by the operating system. No audio codec or ALSA Rust dependency is added in M0. A distribution license/security audit remains part of M5.
